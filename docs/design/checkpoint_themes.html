Checkpoint themes

Eight launch themes, each shown on the real screens. Every theme keeps the same three color roles: one for the app itself (navigation, selection, status), one for reviews and ratings, one for lists and social. What changes is the hue under each role, chosen so the three stay distinct on that background and every button reads clearly.

Switch the screen to compare all eight on the same view.

How this ships

  • One block per theme in theme.css. Each theme redefines the same token names under its own selector, for example [data-app-theme="forest"]. No component changes.
  • The three roles never move. A review is always the review color, a list is always the list color. Only the hue under the role changes, so Dark Green and Purple swap which hue does which job to avoid clashing with their own background.
  • Light themes add two tokens. A soft card shadow, since borders alone disappear on white, and darker text versions of each accent so labels stay readable.
  • Stars stay gold everywhere. They darken slightly on light grounds. Game cover art is never tinted by the theme.
  • No orange in any theme. The three-accent rule holds across all eight.
