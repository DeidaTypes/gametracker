What changes from today

• The card is as tall as its content when there is nothing to show. No full-height empty box, no stranded Cancel at the bottom.
• Cancel is in the top bar, like every other box. The footer is gone.
• The empty text is a compact centered state with a line icon, not a left-flush sentence.
• With recent games, a cover row and the library list fill the card. Typing swaps the list for results in place; the card does not resize.
• The field does not focus itself. The keyboard comes up when you tap it, after the fade.
• Picking a game does not close and reopen anything: the same card crossfades to the review / journal / session form (240 ms), title changes to the game.

Shell: CenteredModal, fade in 260 ms (scale .96 → 1), out 220 ms, no blur. Empty card: top bar 48 · field 44 · empty state ≈ 150 → about 290 pt tall, centered. Full card: 78% of the viewport (same as Ask), list scrolls inside. Row: 44×60 cover, title 15/600, meta 12 muted. Label: 11/700 uppercase, .08em. Tokens only: --bg-surface, --bg-base (field), --border-subtle, --text-*, --accent.
