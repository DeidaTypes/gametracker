04 · THE ONE DOOR

Profile ⋯, four items

This is a floating sheet with the same line icons. Settings is the only row with a chevron, because it's the only one that goes somewhere deeper. The sheet no longer duplicates Privacy, Notifications, Feedback or Log out.

What changed from v1

The colored icon tiles and emoji glyphs are gone, replaced by 18px line icons in muted grey. There are no uppercase section labels, no bordered cards, and no blue "Edit profile ›" link. The type is larger and quieter (14.5px rows, 28px title), and the hairlines are inset to the text.

Color

Accent appears only on active things: switches, the search caret, the nav pill. Sign out uses the danger token (not orange). Everything reads from theme tokens, so it works on Cream and Light Pink with no navy bar.

Routing (unchanged from v1)

Hub → Appearance · Accessibility · Account · Privacy & safety · Invite · Help & about. Edit profile opens in place. The Notifications row stays hidden until it exists. "Sign out" everywhere.
