Search bars that clear

Adding a game from a search clears the words at once and keeps the cursor in the field, so the next search starts right away. While there's text, a small clear button sits in the bar. The same behavior goes everywhere a search adds something: Add games to a list, the + button's game search, the onboarding pickers. Type in the field, then tap + on a result.

  • Add, then it's gone. Tapping + on a result adds the game, shows the capsule with its cover, and empties the field in the same tap. Focus stays in the field, the keyboard stays up, the list goes back to "In this list" below. No reaching for a backspace.
  • Clear button. A small ⨯ in a soft circle appears inside the bar as soon as there's text (it scales in, 220 ms) and disappears when the field is empty. Tapping it clears and keeps focus. It's the same control iOS uses, drawn in the app's tokens.
  • Everywhere, the same. One shared search field (icon left, clear right, 44 pt pill, theme surface) used by Add games to a list, the + button's game search, the favorites and playing-now pickers in onboarding, and the Search page's bar. Today each of these draws its own.
  • Mid-search feedback. "Searching…" and "No games named ‘x’" keep their current wording, inside the same field family.
